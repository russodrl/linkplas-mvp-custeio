# Linkplas MVP, Assistente de Custeio

Apresentação navegável em HTML para demonstrar o MVP do Assistente de Custeio e Orçamentação da Linkplas.

- Upload de documentos técnicos
- Extração assistida por IA
- Revisão humana obrigatória
- Validações para injeção plástica
- Ligação ao Excel atual de custeio
- Roadmap faseado do MVP
